# Stop Slop

Eliminate predictable AI writing patterns from prose.

## Modes

**Edit (default).** Rewrite the draft. Cut slop. Keep the writer's voice. Change only what the rules require.

**Detect / audit.** Do not rewrite. For each hit: name the pattern, quote the line, give a short fix.

```
Faux-insight setup
> "What nobody tells you is the queue is the product."
Fix: "The queue is the product."
```

## Core Rules

1. **Cut filler phrases.** Remove throat-clearing openers, emphasis crutches, and empty adverbs. Keep an adverb when it carries real emphasis, uncertainty, or spoken rhythm. See [references/phrases.md](references/phrases.md).

2. **Break formulaic structures.** Avoid binary contrasts, negative listings, dramatic fragmentation, rhetorical setups, false agency, and the manufactured-insight patterns in [references/structures.md](references/structures.md).

3. **Use active voice.** Every sentence needs a human subject doing something. No passive constructions. No inanimate objects performing human actions ("the complaint becomes a fix").

4. **Be specific.** No vague declaratives ("The reasons are structural"). Name the specific thing. No lazy extremes ("every," "always," "never") doing vague work. No weasel attribution ("experts agree," "studies show"): name the source or cut the claim. Never invent a source.

5. **Put the reader in the room.** No narrator-from-a-distance voice. "You" beats "People" when the draft is already distant. If the writer is already in the scene, leave their stance.

6. **Vary rhythm.** Mix sentence lengths. Two items beat three. End paragraphs differently. Treat em dashes as a rhythm crutch: cut them by default. In a longer draft, keep a rare one if a comma, period, or parenthesis is worse.

7. **Trust readers.** State facts directly. Skip softening, justification, hand-holding.

8. **Cut quotables.** If it sounds like a pull-quote, rewrite it.

9. **Preserve the writer's voice.** Keep distinctive cadence, bluntness, humor, uncertainty, and digressions. Make the minimum effective edit. Do not flatten every draft into the same punchy house style.

## Quick Checks

Before delivering prose:

- Empty adverb? Cut it. Keep it if it carries emphasis, uncertainty, or spoken rhythm.
- Any passive voice? Find the actor, make them the subject.
- Inanimate thing doing a human verb ("the decision emerges")? Name the person.
- Sentence starts with a Wh- word? Restructure it.
- Any "here's what/this/that" throat-clearing? Cut to the point.
- Any "not X, it's Y" contrasts? State Y directly.
- Three consecutive sentences match length? Break one.
- Paragraph ends with punchy one-liner? Vary it.
- Em dash used as a rhythm crutch? Remove it. Keep a rare one only when a comma, period, or parenthesis is worse.
- Vague declarative ("The implications are significant")? Name the specific implication.
- Narrator-from-a-distance ("Nobody designed this")? Put the reader in the scene.
- Meta-joiners ("The rest of this essay...")? Delete. Let the essay move.
- Weasel attribution ("studies show") with no named source? Name it or cut it. Do not invent one.
- Faux-insight, colon-reveal, puffery, -ing clause, synonym cycling, profound kicker, metadiscourse, or formatting slop? See [references/structures.md](references/structures.md).

## Scoring

Rate 1-10 on each dimension:

| Dimension | Question |
|-----------|----------|
| Directness | Statements or announcements? |
| Rhythm | Varied or metronomic? |
| Trust | Respects reader intelligence? |
| Authenticity | Sounds like this writer, or like generic AI? |
| Density | Anything cuttable? |

Below 35/50: revise.

## After an edit

Pass/fail. Any fail means revise. Full checklist: [references/eval.md](references/eval.md).

- Voice intact? Cadence, bluntness, humor, uncertainty, digressions still there.
- Minimum edit? You changed slop, not the writer's clean sentences.
- Empty adverbs gone? Remaining ones earn their place.
- Em dashes gone, or one rare case where a comma, period, or parenthesis is worse?
- New tells gone? Faux-insight, colon-reveal, puffery, -ing clauses, weasel cites, synonym cycling, kickers, metadiscourse, formatting slop.
- Score 35+/50?
