# Post-Edit Self-Check

Run this after an edit. Audit mode uses the same list without rewriting.

Any fail means revise. Then score the draft (SKILL.md). Below 35/50: revise.

## Voice and scope

| Check | Pass | Fail |
|-------|------|------|
| Voice | Cadence, bluntness, humor, uncertainty, digressions still there | Flattened to the same punchy house style |
| Minimum edit | Only slop changed | Clean sentences rewritten for style |
| Mode | Edit rewrote; audit named, quoted, and suggested | Audit rewrote, or edit ignored voice |

## Soft rules

| Check | Pass | Fail |
|-------|------|------|
| Empty adverbs | Gone | Empty -ly words, softeners, or intensifiers remain |
| Kept adverbs | Remaining ones carry emphasis, uncertainty, or spoken rhythm | Stripped an adverb that changed the meaning |
| Em dashes | None, or one rare case where a comma, period, or parenthesis is worse | Used as a rhythm crutch |

## Tells

| Check | Pass | Fail |
|-------|------|------|
| Faux-insight | Claims stand without a "nobody tells you" setup | Secret-announcing openers remain |
| Colon-reveal | No "The best part: [punchline]" drama | Label-colon-punchline leftovers |
| Importance puffery | Significance shown with a concrete change | "Pivotal," "testament," "underscores" with no fact |
| -ing analysis | No caption clauses after the act | "Highlighting the team's commitment..." remains |
| Weasel attribution | Sources named, or the sourceless claim is cut | "Studies show" with no study, or a source you invented |
| Synonym cycling | Same actor or tool keeps one name | Thesaurus rotation for one thing |
| Kickers | Ends on the last real point | Fake-profound closer or recap paragraph |
| Metadiscourse | No "the key point is" wrappers | Interpretive labels around sentences |
| Formatting slop | Plain headings, no emoji titles, no decorative bold | Poster formatting |

## Score gate

| Check | Pass | Fail |
|-------|------|------|
| Scoring | 35+ / 50 on Directness, Rhythm, Trust, Authenticity, Density | Below 35 |

Authenticity here means "sounds like this writer," not "sounds like a generic clean edit."
